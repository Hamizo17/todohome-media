# Web TODOHOME (todohome-es.vercel.app)

Fuente de la tienda. Productos en data.py: `query` lleva el código ASIN (enlace directo /dp/ASIN?tag=todohome-21) o un texto de búsqueda.
Fotos libres de Pexels en photos.py (nunca fotos descargadas de Amazon).
Despliegue: el build de Vercel descarga estos archivos de un commit concreto de este repo y ejecuta build.sh.
